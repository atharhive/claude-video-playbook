# Opus Video Prompts

Collection of 703 viral video prompts and motion graphics recipes created with Claude Opus 5.5.

## CLI Search Tool
Run directly from terminal:
```bash
find-video-prompt "explainer"
find-video-prompt "3d"
find-video-prompt "kinetic typography"
find-video-prompt "particles"
```

Data location: `/home/ubuntu/tools/awesome-opus5-5-videos/prompts/` and `/home/ubuntu/tools/awesome-opus5-5-videos/data/videos.json`.
