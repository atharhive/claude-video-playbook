# Example 07: Project NOMAD 10s Papercut Hook

> Visually accurate stop-motion papercraft explainer breaking down Project NOMAD (`Crosstalk-Solutions/project-nomad`).

## Overview

A 9.9-second vertical video (1080x1920 at 30 fps, 297 frames) built with Remotion. Directly recreates the exact hook from Instagram reel `DfcGetLzyuk`:
1. **Scene 1 (Blackout Hook):** "THE WORLD GOES OFFLINE" banner, night city blackout skyline, severed ethernet cable with disabled WiFi icon and sparks.
2. **Scene 2 (Project NOMAD):** "MADE FOR THAT DAY" taped banner, official repository card with 43,000+ stars, OFFLINE tag, and the 3 offline capabilities (Wikipedia 125GB, Local AI Ollama+Qdrant, ProtoMaps offline GIS).

## Structure & Architecture

- **Visuals:** SVG torn-paper layers, drop shadows, physical masking tape corners, and papercraft explorer mascot.
- **Narration:** Single clear voice with zero background music.
- **Audio:** Mastered to EBU R128 (-14 LUFS) with procedural paper whooshes and tape pulls.
